# CNC3-Voices-eng

Command & Conquer 3 unit voice lines (English), for Command & Conquer Remastered Collection mods (Red Alert). One of the asset packs from [Tiberian Factions](https://github.com/gibbo101/cnc-ra-tiberian-factions).

## Contents

**Sounds (Data/AUDIO)** (35): C3MATA, C3MATB, C3MATC, C3MATD, C3MATE, C3MATF, C3MMOA, C3MMOB, C3MMOC, C3MMOD, C3MMOE, C3MMOF, C3MSEA, C3MSEB, C3MSEC, C3MSED, C3MSEE, C3MSEF, C3PATA, C3PATB, C3PATC, C3PATD, C3PATE, C3PATF, C3PMOA, C3PMOB, C3PMOC, C3PMOD, C3PMOE, C3PSEA, C3PSEB, C3PSEC, C3PSED, C3PSEE, C3PSEF

## Using it

1. Copy the files under this pack's `Data/` folder into your mod's `Data/` folder, keeping the paths.
2. Copy the entries you need from this pack's XML files into your mod's own XML files:

   - `Data/XML/AUDIO/SFXEVENTSNONLOCALIZED_CNC3.XML` into `Data/XML/AUDIO/SFXEVENTSNONLOCALIZED.XML`

   The launcher only reads the mod files on the right. This pack's own XML files are there to copy from, so enabling the pack by itself changes nothing in game.
