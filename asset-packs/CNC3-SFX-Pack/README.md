# CNC3-SFX-Pack

Command & Conquer 3 weapon sound effects, for Command & Conquer Remastered Collection mods (Red Alert). One of the asset packs from [Tiberian Factions](https://github.com/gibbo101/cnc-ra-tiberian-factions).

## Contents

**Sounds (Data/AUDIO)** (25): C3MGUN1, C3MGUN10, C3MGUN11, C3MGUN12, C3MGUN2, C3MGUN3, C3MGUN4, C3MGUN5, C3MGUN6, C3MGUN7, C3MGUN8, C3MGUN9, C3MPOD1, C3MPOD2, C3MPOD3, C3MPOD4, C3PGUN1, C3PGUN2, C3PGUN3, C3PGUN4, C3PGUN5, C3PGUN6, C3PGUN7, C3PGUN8, C3PGUN9

## Using it

1. Copy the files under this pack's `Data/` folder into your mod's `Data/` folder, keeping the paths.
2. Copy the entries you need from this pack's XML files into your mod's own XML files:

   - `Data/XML/AUDIO/SFXEVENTSNONLOCALIZED_CNC3.XML` into `Data/XML/AUDIO/SFXEVENTSNONLOCALIZED.XML`

   The launcher only reads the mod files on the right. This pack's own XML files are there to copy from, so enabling the pack by itself changes nothing in game.
