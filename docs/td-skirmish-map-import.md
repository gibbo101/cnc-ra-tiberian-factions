# TD skirmish maps in the RA mod

**Status:** Parked. The 31 maps in `parked/td-maps/` are the old conversion, desert on the interior
slot with TD's tiles spliced into RA's tilesets; they are out of the mod from 5.0.0.

`scripts/td_map_to_ra.py` converts a TD map to RA format in TD's own theatre (`td-base-art.md`).
TD's maps reach the Official list through the carrier, from TD's own files (`td-base-art.md`), so
the parked maps and their custom-map install are replaced, not brought back.
